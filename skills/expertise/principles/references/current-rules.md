# Current rules

A branch moves on, to the owner, to whoever lands it, or onto the branch it lands on, only once it is shown to meet the rules that hold now. Recheck it against each skill and agent definition that wrote or judged its commits:

1. **Find each one** from the loads in the session record where one is installed, else from the skills its task route and reviews name and the agent definitions that started its agents.
2. **Read each one's history** in its source, the repo its loaded path sits in, over the skill's directory and the agent definitions, after the start of the branch's last review, read from the session record where one is installed, else the time the branch was last sent out for review.
3. **Sort the result.** With no commit there, the branch's reviews still hold. A commit there, or a source that cannot be read as a repo, leaves the branch judged under a rule it is not shown to meet; the skill that names this principle says where it goes.

A running session reads a skill's current text each time it loads it with the Skill tool, and a subagent reads each skill it preloads as it stands when that subagent starts. An agent definition stays as the top-level session read it at its start, until its plugins reload, so a running session cannot load a changed one.
