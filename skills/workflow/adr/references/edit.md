# Edit

1. **Read the record, what changed, and the code it claims.** Re-verify every claim, including the ones the change leaves alone, since this is where drift is found.
2. **Find everything the change touches** across the other records and the owning docs, by searching the topic as well as links to the record number.
3. **When the decision still holds,** rewrite the record to the current state. A rejected alternative that became the choice moves into the Decision.
4. **When it no longer holds, never earned a record, or duplicates its owning doc,** delete the record and its index line, and move a convention to the agent rules.
5. **Change the owning docs and the other records in the same change**, so every doc agrees with the records.
