# A new doc

A subject with no documentation home gets a doc of the type below that fits it. Give it the structure the repo's docs of that type share, or the template where they share none, and link the docs that own adjacent context.

## Doc types

- **Architecture:** system layout, trust boundaries, data flows and request paths.
- **Design:** schema, column definitions, indexes, constraints and transactional functions.
- **Security:** threat model, severity matrices and build invariants.
- **Runtime:** behavior during a request, such as the lifecycle, tool execution and memory.
- **Reference:** tables and lists, such as CLI commands, configuration options and error codes.
- **Comparison:** feature matrices and benchmark results.

## Template

Omit a section that does not apply.

```
# [Topic]

One-sentence summary of what this doc covers.

## [Primary content]

Tables, charts, and bullets.

## Design rule

One paragraph. What principle explains why this design is the way it is?
```
