# Test

When: a change only to tests, or to the spec wording those tests prove.

1. The branch or worktree the repo prescribes.
2. `test-writing`: name the bug each test catches, and prove it can fail.
3. `test-review` on the tests written.
4. Each commit: `simplify`, then `design-review` by a fresh agent.
5. The repo's checks.
6. Land as the repo's rule says.

Report: the bug each test catches, and how each was proven able to fail.
