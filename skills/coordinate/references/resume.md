# Resume

When: after context compaction, or when a session picks up earlier work.

1. Load `coordinate` again and read the task list, or rebuild it from the handoff and the checkout the work lives in (`git worktree list`, `git status`, `git log`). Write a plan that lives only in the handoff to the repo or the coordinator's working files, so compaction cannot lose it.
2. Load the current step's skill, and `code-writing` before any further edit.

Report: the route, the step it resumed at, and the checkout.
