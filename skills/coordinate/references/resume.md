# Resume

When: after context compaction, or when a session picks up earlier work.

1. Load `coordinate` again. Where a ledger file exists, read it first, then `git log`. Otherwise read the task list, or rebuild it from the handoff and the checkout the work lives in (`git worktree list`, `git status`, `git log`).
2. Write a plan that lives only in the handoff to the ledger or the repo, so compaction cannot lose it.
3. Load the current step's skill, and `code-writing` before any further edit.

Report: the route, the step it resumed at, and the checkout.
